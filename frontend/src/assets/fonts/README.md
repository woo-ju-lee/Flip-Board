# Board typeface

`IBMPlexSansKR-Regular.woff2` is IBM Plex Sans KR Regular (400), the original complete hinted WOFF2 distributed by IBM. It is bundled locally for Korean and numeric character flaps; the controls retain their existing Noto Sans KR styling.

- Source: https://github.com/IBM/plex/blob/master/packages/plex-sans-kr/fonts/complete/woff2/hinted/IBMPlexSansKR-Regular.woff2
- Copyright: IBM Corp., with Reserved Font Name "Plex".
- License: SIL Open Font License 1.1, copied to `frontend/public/licenses/IBM-Plex-Sans-KR-OFL.txt` and included in Windows and standalone HTML distributions.

The font outlines are unmodified. The supplied font supports all 11,172 modern Hangul syllables.
