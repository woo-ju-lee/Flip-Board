## 브라우저 검사 재현

먼저 기본 설정(`KORAIL_LIVE_ENABLED=false`)으로 빌드·서버를 실행합니다. 이 스크립트는 기본 빈 운영 선로 카탈로그를 전제로 합니다. 다른 검증 데이터를 등록했다면 기대 결과도 그 범위에 맞게 검토해야 합니다.

```bash
cd frontend
npm install --no-save --package-lock=false playwright@1.57.0
npx playwright install chromium
cd ..
node scripts/browser_smoke.mjs
```

기존 Chromium이 있으면 `KORAIL_BROWSER_EXECUTABLE`로 실행 경로를 지정합니다. 별도 설치의 Playwright는 `KORAIL_BROWSER_MODULE`로 `index.mjs` 경로를 지정할 수 있습니다. 기본 검사 대상은 `http://127.0.0.1:8000`; 변경은 `KORAIL_TEST_URL`입니다. 스크립트의 네트워크 차단은 로컬 테스트 페이지에만 적용됩니다.

## 실제로 검증하지 못한 항목

- 현재 코레일 GIS API의 HTTP 200 응답·사용 허가·호출 제한. 과거 제공 기록의 성공과 이번 실행의 성공은 다릅니다.
- 실제 경부고속선·호남고속선 geometry와 일반선 병행·분기점의 전체 커버리지.
- 실제 열차의 물리 노선 정답과 비교한 정확도·오탐률·미탐률. 합성 도형의 테스트 통과로 운영 정확도를 주장하지 않습니다.
- 장시간 수집, 운영 서버 배포, 다중 인스턴스, Safari/Firefox, 실제 모바일 기기.
- 실제 스피커에서 소리를 듣는 청감 검증. 오디오 합성과 사용자 활성화 흐름만 테스트했습니다.
- 원본 열차 목록의 전국 모든 열차 포함 여부, 위치 좌표의 센서 원천, 병결·분리 사례의 완전한 식별.

## 현재 운영 범위

전체 열차 기록 시연은 실행 가능합니다. 수집·필터 파이프라인은 구현되어 있고 모의 HTTP 및 합성 도형으로 통합 검증했습니다. **실시간 경부고속선 열차 표시의 최종 목표는 아직 외부 조건이 충족되지 않았습니다.** 허용된 실시간 접근과 검증된 선로 데이터를 확보해야 합니다.

모호·미확인 매칭은 해당 노선 표시에서 제외합니다. 초기 데이터는 울산 연결만 제공하고, 검증된 geometry가 0개이므로 노선 선택은 `unavailable`로 안내합니다. 출발·목적지·KTX 이름으로 빈 필터를 임의로 채우지 않습니다.
