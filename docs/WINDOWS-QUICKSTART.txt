FlipBoard — Windows 무설치 실행

1. FlipBoard-버전-windows-x64.zip의 압축을 전부 풉니다.
2. FlipBoard 폴더 안의 FlipBoard.exe를 더블클릭합니다.
3. 준비가 끝나면 기본 브라우저에서 전광판이 열립니다.

Python, Node.js, 가상환경, 관리자 권한은 필요하지 않습니다.
FlipBoard.exe와 _internal 폴더를 함께 보관하세요. EXE만 옮기면 실행되지 않습니다.
GitHub의 'Source code (zip)'이나 'Download ZIP'은 개발용 소스입니다.
실행용 파일은 Windows 빌드 결과 또는 Release의 windows-x64.zip입니다.

작은 실행 창
- 브라우저 열기: 현재 실행 중인 전광판을 다시 엽니다.
- 실시간 수집: 체크하고 '적용 후 재시작'을 누르면 저장됩니다.
- 로그 폴더: 실행 오류 기록을 확인합니다.
- 종료 또는 창 닫기: 전광판 서버와 수집기를 종료합니다.
- F6: 수집 체크 변경, F5: 적용 후 재시작, Esc: 종료.
브라우저만 닫으면 서버와 수집은 계속 실행됩니다.
설정 적용 중에는 같은 주소를 유지하며 브라우저 탭을 추가하지 않습니다.

설정과 업데이트
- 처음 실행하면 실시간 수집이 켜집니다. 음소거는 기존과 같이 기본 켜짐입니다.
- 설정: %LOCALAPPDATA%\FlipBoard\.env
- 로그: %LOCALAPPDATA%\FlipBoard\logs\flipboard.log
- 기존 소스의 .env를 가져오려면 첫 실행 전에 EXE 옆에 복사하세요.
  이미 사용자 설정이 있으면 EXE 옆 설정으로 덮어쓰지 않습니다.
- 새 버전은 별도 폴더에 압축 해제하고 이전 버전을 종료한 뒤 실행하세요.
  사용자 설정은 계속 유지됩니다. 자동 업데이트는 하지 않습니다.

실시간 수신은 인터넷 연결과 코레일 원본 응답에 따라 달라집니다.
실시간 수신 실패는 전광판의 연결 상태에서 확인하세요.
'기록 표본'은 저장된 과거 자료이며 현재 운행 정보가 아닙니다.
8000번 포트가 사용 중이면 다른 빈 포트로 실행되며 실행 창에 주소가 표시됩니다.

지원: Windows 10/11 x64. 설치 프로그램과 트레이 상주는 포함하지 않습니다.
